2. 듀얼 레일 — 같은 목적지, 다른 심리

웜 숏츠 오가닉 (YT / FB / IG)

  • 감정: 호기심 · 시각 충격 (10초)
  • 노출: 피드 → 첫댓글 /r → 쇼룸 (entry=shorts)
  • 위험: 재미만 소비하고 클릭 없음
  • 한 일: 「이 변화, 우리 업종일까?」클릭 유도

콜드 SEO · 키워드 광고

  • 감정: 문제 해결 의도 (검색어에 이미 니즈)
  • 노출: SERP → thin 랜딩(업종 프리셋) → 쇼룸/사례
  • 위험: 키워드 ≠ 첫 화면 → 즉시 이탈
  • 한 일: 검색어 = 첫 카드/사례가 바로 맞게

3. 고객 여정 × 회사 노출면 × 행동 / 이탈 × 회수

단계 노출되는 곳 고객 행동 이탈 패턴 회수 레버
0. 주의 숏츠 피드 / 검색 SERP 스크롤·스킵 / 클릭 스킵 = 무관심 동일 현장 2차 컷 · 해시태그 리타깃
1. 호기심 /r/yt · /r/ig · /r/fb → 쇼룸 진입 · 3초 체류 랜딩 과부하 즉시 이탈 UTM 리타깃: 「같은 업종 B/A」만
2. 이해 고민 1개 + B/A 1세트 선택 · 스와이프 선택 회피 (정보 과다) 미선택 업종 질문형 광고
3. 확신 사례 페이지 · 블로그 자세히 보기 · 스크롤 사례 미완성 · CTA 안 보임 열람 중도이탈 → 사례 완성본 리마인드
4. 행동 Sticky / 상담 CTA 클릭 · 문의 작성 CTA 직전 이탈 최대 (시뮬 ~80–85%) 「견적 범위만 알려드릴까요」저마찰 CTA
5. 전환 채널톡 · 영업 답장 · 미팅 · 견적 응답 지연 · 니즈 불일치 미응답 24h 팔로업 + 현장 사진 요청

Source: 공개 쇼룸 ABM · /r 숏츠 랜딩 · 케이스 블로그 · 상담 CTA · 에이전트 시뮬 추정치

4. 자산 맵 — 무엇을 어디에 쓸지

자산 담당 단계 역할 운영
숏츠 영상 주의 · 호기심 10초 B/A 오가닉 + 부스팅
첫댓글 /r/* 호기심 → 랜딩 채널별 UTM 자동 게시
오픈쇼룸 이해 · 확신 고민 → B/A → 사례 ABM 실측
사례 블로그 확신 (검색도) 긴 근거 · SEO 정본 + 네이버 수기
상담 / 채널톡 행동 · 전환 문의 · 견적 영업
리타깃 소재 이탈 회수 단계별 메시지 광고 + CRM

5. 누수 TOP (지금 구조 기준)

누수 지점 이탈 강도 원인 가설 퍼널 처방
고민 카드 선택 전 ~64% 쇼룸이 카탈로그처럼 보임 첫 화면 = 업종/고민 1질문만
B/A → 사례 열기 ~58% 앨범과 블로그 CTA 구분 약함 사례 1개 고정 노출 + 「왜 이 현장」
상담 CTA 직전 ~80–85% 증거는 봤는데 결정 비용 큼 저마찰 CTA: 견적 범위 / 도면 검토
숏츠 시청 후 미클릭 다수 재미는 있으나 다음 행동이 없음 첫댓글 /r + 고정댓글 질문형 CTA
검색 랜딩 미스매치 중 키워드 ≠ 쇼룸 첫 화면 키워드별 thin 랜딩 (업종 프리셋)

시뮬 메모

ABM 에이전트 시뮬에서 상담 CTA 직전 이탈이 가장 큼. 쇼룸을 더 채우기보다 CTA 마찰을 낮추는 편이 레버리지가 크다.

6. 이탈자 회수 루프

이탈 세그먼트 신호 회수 메시지 채널
시청만 함 숏츠 조회 · 완주 동일 현장 다른 앵글 / 시공 디테일 컷 YT · Meta 리타깃
랜딩 이탈 <10초 ABM enter + bounce 「당신 업종 B/A 3장」카드 광고 Meta / GAds
고민 미선택 enter, no card 선택지 3개만 묻는 퀴즈형 랜딩 리타깃 + 카톡
사례까지 봄 case_open 블로그 요약 1통 + 상담 슬롯 CRM / 채널톡
상담 미클릭 cta_view, no click 「견적 범위만」마이크로 전환 리타깃 + 문자
문의 후 무응답 lead created 24h / 72h 시퀀스 + 자료 요청 영업 자동화

7. 운영 규칙

장면당 일 1개

숏츠=클릭, 랜딩=고민 선택, 사례=상담. 동시에 두 일을 시키지 않는다.

합류는 쇼룸

숏츠·검색·광고 모두 UTM으로 쇼룸에 모은 뒤, ABM으로 단계를 잰다.

회수는 단계별

전 이탈자에게 같은 광고를 쏘지 않는다. 신호별로 다음 장면만 보낸다.

다음 설계 우선순위

1) 숏츠 → /r → 쇼룸 thin 입구(고민 1질문) 고정 · 2) 키워드별 업종 프리셋 랜딩 · 3) CTA 직전 마이크로 전환 · 4) 이탈 세그먼트 × 리타깃 메시지 매트릭스를 ABM 실측과 연결
