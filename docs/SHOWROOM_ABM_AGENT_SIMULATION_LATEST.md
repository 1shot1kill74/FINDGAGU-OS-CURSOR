# Showroom ABM Agent Simulation (1000 agents)

동일 1000명 페르소나를 before/after UX 가정으로 각각 시뮬레이션한 결과입니다.
실제 라이브 데이터가 쌓이기 전, 이번 개선의 방향성을 검증하는 **모델 추정치**입니다.

|------|--------|-------|------|
| 스토리 루트 상담 클릭률 (방문 대비) | 0.2% | 2.8% | +1300.0% |

### 에이전트 관찰 메모 (개선 레버)

- 가장 큰 이탈: **갤러리 상담 클릭** 직전 구간 (89.5% 이탈, 약 128명).
- 고민 카드까지 오지만 선택하지 않는 비율이 높습니다. 카드 카피·스크롤 위치·「성공 사례 보기」 인지도를 점검하세요.
- B/A는 보지만 사례 페이지로 넘어가지 않습니다. 블로그 티저·「자세히 보기」 CTA가 약해 보일 수 있습니다.
- 사례 열기 후 로드 실패/미완성 추정 13건. case 링크·콘텐츠 완성도를 실측(abm_case_open_fail)으로 확인하세요.
- 사례까지 본 사람 중 상담 클릭 전환은 여전히 낮습니다. Sticky CTA 카피·노출 타이밍·채널톡 오픈 신뢰도가 병목일 수 있습니다.
- 사진 루트는 갤러리 진입 자체가 어렵습니다. 「시공 사례 사진 바로 찾기」 섹션 가시성·탭(업종/제품/색상) 발견성을 확인하세요.
- 전체 방문 대비 상담 클릭은 아직 낮은 편입니다. 시뮬 추정치이므로 **실측 ABM 대시보드**(`/admin/showroom-abm`)로 교차 검증하세요.

> ⚠️ 확률 모델 기반 추정입니다. 실제 병목은 `/admin/showroom-abm` 실측 이벤트로 확인하세요.
