# 고객 후기 질문지 샘플 (수동 카톡용)

> 1차는 **직접 카톡 발송 + 링크**로 테스트합니다. 반응이 괜찮으면 알림톡 템플릿으로 옮깁니다.

## 샘플 페이지

- 로컬(직원용): `http://localhost:5180/review/sample?staff=1`
- 고객용 링크: `http://localhost:5180/review/sample?site=정발산%20관리형&name=김원장`

---

## 질문지 (3문항)

| # | 문항 | 필수 | 가이드 |
|---|------|------|--------|
| 1 | 시공 전, 가장 걱정했던 점 | ✅ | 한 줄, 120자 이내 |
| 2 | 시공 후, 가장 달라진 점 | ✅ | 한 줄, 120자 이내 |
| 3 | 비슷한 업종 원장님께 한 마디 | 선택 | 한 줄, 120자 이내 |

### 동의 문구 (필수)

> 익명 또는 지역·상호 일부 마스킹 후 마케팅·시공사례 페이지에 사용해도 됩니다.

---

## 1차 카톡 (링크 보내기)

```
{이름}님, 안녕하세요. 파인드가구입니다.
시공 후 공간은 잘 쓰고 계신가요?
({현장명} 시공 건 기준)

다른 원장님들께 도움이 될 수 있도록
한 줄 후기만 부탁드립니다. (약 1분)

👉 {후기 링크}

바쁘시면 아래 3가지만 카톡으로 답 주셔도 됩니다.
1) 시공 전 걱정
2) 시공 후 달라진 점
3) 비슷한 업종 원장님께 한 마디 (선택)
```

---

## 리마인드 카톡 (3~5일 후, 미응답)

```
{이름}님, 혹시 바쁘셨을까요?
후기는 짧게 한 줄만 적어주셔도 큰 도움이 됩니다.

👉 {후기 링크}
```

---

## 감사 카톡 (제출 후)

```
{이름}님, 소중한 후기 감사합니다.
확인 후 사례 자료에 반영할 수 있도록 검토하겠습니다.
좋은 공간 운영 응원드립니다.
```

---

## 카톡 답장만 받는 경우 (링크 없이)

고객이 링크 대신 카톡으로만 답할 때는 아래 형식으로 받으면 정리하기 쉽습니다.

```
1) 시공 전 걱정:
2) 시공 후 달라진 점:
3) 원장님 한 마디:
4) 사례 활용 동의: 예 / 아니오
```

---

## 알림톡 전환 시 메모

반응률이 괜찮으면 아래만 알림톡 템플릿 심사용으로 옮기면 됩니다.

- 본문: 시공 후기 요청 + `{고객명}` + `{현장명}`
- 버튼: `후기 남기기` → `{review_url}`
- 실제 3문항 입력은 **웹 폼**에서 처리 (알림톡 안에 폼 불가)

---

## 운영 체크

- [ ] 시공완료 후 **7일** 정도 지나서 1차 발송
- [ ] 미응답 시 **3~5일 후** 리마인드 1회
- [ ] 제출 후 Admin에서 **승인 전에는 쇼룸·콘텐츠에 미반영**
- [ ] 좋은 후기만 선별해 카드뉴스 evidence / 블로그에 사용
